# Firmware — ESP32 전자 청진기 펌웨어

ICS43434 I2S MEMS 마이크로 심장음/호흡음을 캡처하고,  
BLE로 모바일에 전송하며, TFT LCD에 실시간 파형과 AI 결과를 표시합니다.

## 하드웨어 구성

| 부품 | 핀 | 역할 |
|------|-----|------|
| ICS43434 WS | GPIO 25 | I2S Word Select |
| ICS43434 SD | GPIO 33 | I2S Serial Data |
| ICS43434 SCK | GPIO 26 | I2S Clock |
| 왼쪽 버튼 | GPIO 35 | 모드 전환 |
| 오른쪽 버튼 | GPIO 0 | 녹음 시작/중지 |
| TFT 백라이트 | GPIO 4 | LCD 밝기 |

---

## 상태 머신

```
ACTIVE ──(버튼L)──→ 모드 전환 (HEART → LUNG → PATIENT → ...)
   │
   └──(버튼R)──→ 5초 녹음 → REC_DONE → AI 대기 (". / .. / ...")
                                              │
                                    ┌─────────┴──────────┐
                                    ▼                    ▼
                              BLE로 AI 결과 수신     30초 타임아웃
                                    │                    │
                                    ▼                    ▼
                              AI_RESULT 팝업        RECHECK 팝업
                           (초록/빨강/주황)         ("다시 청진해 주세요")
```

---

## BLE 프로토콜

| UUID | 용도 |
|------|------|
| `19b10000-...1214` | Service |
| `19b10001-...1214` | Audio (Notify) — 80 samples x int16 |
| `19b10002-...1214` | Command (Write) — AI 결과 수신 |

---

## 빌드

1. Arduino IDE → 보드: `ESP32 Dev Module`
2. 라이브러리: `TFT_eSPI`, `ESP32 BLE Arduino`
3. 최신 파일(`2026-04-05-2130.h`)을 `.ino`에서 `#include`
4. 업로드 (115200 baud)
